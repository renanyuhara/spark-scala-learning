# Projeto final — Sales Data Pipeline

Vamos construir este projeto progressivamente enquanto aprendemos as ferramentas.

## Cenário

Uma equipa recebe transações comerciais de diferentes fontes. É preciso validar, transformar e agregar os dados para produzir resultados consistentes para análise.

## Objetivo final (a evoluir com as aulas)

- Ler dados em lote a partir de CSV e JSON.
- Identificar dados inválidos e duplicados.
- Calcular métricas por produto e cidade.
- Guardar os resultados em Parquet.
- Comparar planos de execução e experimentar formas de melhorar a performance.
- Acrescentar testes automatizados quando migrarmos para um projeto compilado com `sbt`.
